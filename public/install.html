Y.D.R.B.N. INSTALLATION GUIDE

Standalone Offline Receiver Setup

🍎 iPhone & iPad (Safari)

  1. Open Safari and navigate to https://lharles.github.io/ydrbn-app/.
  2. Tap the Share button (box with an upward arrow) in the bottom toolbar.
  3. Scroll down the action sheet and tap Add to Home Screen.
  4. Confirm the title and tap Add in the top-right corner.

🤖 Android (Chrome)

  1. Open Chrome and navigate to https://lharles.github.io/ydrbn-app/.
  2. Tap the pulsing Install icon in the top receiver bar (or open Chrome's three-dot ⋮ menu).
  3. Select Install app (or Add to Home screen).
  4. Confirm the prompt. The app will install directly into your app drawer as a standalone PWA.

💻 Desktop (Chrome, Edge, Brave)

  1. Navigate to the application URL in any Chromium-based browser.
  2. Click the Install icon located on the right side of the address bar.
  3. Click Install to launch Y.D.R.B.N. inside its own distraction-free desktop window.
